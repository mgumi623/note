# 医療情報セキュリティの全体像

## このノートの目的

病院の電子カルテシステムを中心とした医療情報セキュリティについて、「何が求められていて」「なぜ必要で」「具体的にどう対応すべきか」を俯瞰的に理解するためのMap of Content（MOC）です。

## 全体構造の整理

医療情報セキュリティは、大きく分けて以下の4つの層で構成されています。

```
┌──────────────────────────────────────────────────┐
│  第1層：法規制（守らなければならない法律）            │
│  医療法施行規則、個人情報保護法、次世代医療基盤法     │
├──────────────────────────────────────────────────┤
│  第2層：ガイドライン（具体的な指針）                  │
│  厚労省ガイドライン6.0、3省2ガイドライン              │
├──────────────────────────────────────────────────┤
│  第3層：組織体制（誰が何をするか）                    │
│  CSIRT、BCP、医療ISAC、インシデント報告              │
├──────────────────────────────────────────────────┤
│  第4層：技術的対策（何を導入するか）                  │
│  EDR、MFA、PAM、ゼロトラスト、マイクロセグメンテーション│
└──────────────────────────────────────────────────┘
```

## 今なぜ医療情報セキュリティが重要なのか

### 被害の深刻化

医療機関へのサイバー攻撃は、単なる情報漏洩にとどまらず、**診療そのものが停止する**という点で、患者の生命に直結します。大阪急性期・総合医療センターでは電子カルテの全面復旧に73日かかり、逸失利益は十数億円以上に達しました。

### 医療DXとのジレンマ

電子処方箋、オンライン資格確認、全国医療情報プラットフォームと、医療のデジタル化が急速に進む一方で、接続ポイントが増えるほどサイバー攻撃の侵入経路も増えます。「便利さ」と「安全性」の両立が最大の課題です。

### 法的義務の強化

2023年4月の医療法施行規則改正により、サイバーセキュリティ確保が法的義務になりました。もはや「対策しなくてもよい」という選択肢はありません。
