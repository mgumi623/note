# 大門恭平：医療DXと患者エンパワーメント——医学知識の民主化を実践する人物

## 序論：「医療のデジタル化」と「患者エンパワーメント」は同じ課題だ

大門恭平という1人の医療従事者の人生には、現代医療システムが抱える根本的な問題が凝縮されています。

一見すると矛盾した2つの活動をしています：

1. **セイワ会医療法人グループ SDX研究所所長** — 医療機関のDXを推進する経営側の立場
2. **小児がん患児の父親** — 医学情報へのアクセスに苦しむ患者家族の立場

しかし、この2つは実は同じ根本的な問題への異なるアプローチなのです。

**その問題とは：「医療情報とテクノロジーへのアクセスの不平等」**

医療DXを推進する立場から、大門恭平は「医療機関がいかに効率的に患者情報を管理・活用するか」を考えています。一方、患者家族の立場からは、「患者が医学情報にいかにアクセスし、自分の治療を選択できるか」を考えています。

この2つの活動を統合する視点が、現在の日本の医療体制に強く求められています。

## Part 1：キャリアの形成

### 医療現場での出発：理学療法士として

**時期：2010年代初頭～**

大門恭平は理学療法士として医療現場でキャリアをスタートさせました。

**理学療法士という職種の特性：**
- 患者と直接向き合う医療職
- 運動学・解剖学・生理学など医学基礎知識を持つ
- しかし、医師のような診断権はなく、医師の指示の下で治療を行う

この経験は後の活動において極めて重要な基礎となります。**患者の視点に立ちながら、医学的な思考ができる**という稀有な視点を持つことになったからです。

#### 理学療法士が直面する医療現場の現実

患者と日々向き合うことで、大門恭平は医療現場の根本的な問題に気づきます：

- **リハビリテーションの効果が見えない**：患者が自分の回復を実感できない
- **スタッフの過重労働**：手作業による記録・報告業務が膨大
- **データの散在**：患者の回復プロセスが可視化されていない
- **医師との情報格差**：医師が持つ情報と、患者・セラピストが持つ情報に大きなギャップ

これらの課題は、すべて**「情報の見えない化」と「デジタル化の不足」**に起因しています。

### デジタルスキルの習得：自分の視野を広げる決断

**時期：2010年代後半～2020年代初頭**

理学療法士としての実務経験の中で、大門恭平は重要な決断をします。

**デジタルハリウッド大学大学院に進学し、デジタルコンテンツ・データ分析・Web技術を学ぶ**

この決断は極めて戦略的です：

- **医療現場の課題を認識している** → だからこそ、その解決にはテクノロジーが必要と判断
- **医学知識を持っている** → だからこそ、テクノロジーが医療に何をもたらすかを理解できる
- **医療職とIT職の間のギャップを埋めたい** → 両者の言葉をつなぐ人材になりたい

### ターニングポイント：医療DXリーダーへの転身

**時期：2020年代初頭～現在**

デジタルスキルを習得した大門恭平は、**セイワ会医療法人グループ SDX研究所の所長**というポジションを得ます。

このポジションの意味：

- 単なる「IT部門の長」ではなく、医療現場の実務知識を持つ者として、医療DXを推進
- 医師や経営層ではなく、患者接点のセラピストレベルからの視点で改革を設計
- 「医療現場のリアルな課題」と「テクノロジーソリューション」を直接つなぐ

**SDX研究所のミッション：「頑張らないといけないリハビリテーションを変える」**

この言葉には、医療従事者としての深い理解が込められています。
- 患者が「頑張らないといけない」と感じるのは、何故か？
- リハビリの効果が見えないから？スタッフの励ましだけに頼っているから？
- **テクノロジーで「見える化」できれば、患者のモチベーションは変わるのではないか？**

## Part 2：医療DX推進活動の詳細

### 直面する日本の医療危機

大門恭平がSDX研究所で取り組む課題の背景を理解するには、日本の医療機関が直面している危機を知る必要があります。

#### 医業赤字という構造的危機

**現状：日本の病院の74.6%が医業赤字（2024-2025年）**

「医業赤字」とは何か：
```
医業赤字 = 診療による収入 - 診療にかかる費用（人件費・薬剤費など）がマイナス
```

つまり、**治療をすればするほど赤字が膨らむ構造**になっています。

なぜこんなことが起きているのか：
1. **診療報酬（治療に対する公定価格）が固定化** — 約20年以上、ほぼ据え置き
2. **医療コストは急速に上昇** — 薬剤費、医療材料費、人件費が毎年増加
3. **医療従事者の賃金が上がらない** — 収入が増えないため、スタッフ賃上げができない
4. **スタッフ不足が深刻化** — 過酷な労働環境から医療職が離職
5. **経営効率の限界** — 非効率な業務をいくら削っても、根本的な赤字は解決しない

この循環を止めるには、**単なるコスト削減ではなく、根本的な業務体制の改革が必須**です。

### DXによる医療機関経営の再設計

大門恭平が推進している医療DXは、この経営危機に対する根本的なアプローチです。

#### 1. 業務効率化による人員削減

**具体的な取り組み：**
- **電子カルテシステムの最適化** → 医師や看護師の事務作業を削減
- **診療支援システムの導入** → 医療スタッフの判断支援、作業時間短縮
- **自動化できる業務の自動化** → 特に事務職の生産性向上

**効果：**
- スタッフの事務作業が週に数時間削減
- その時間を患者対応に回せる
- 結果として、患者体験が向上

#### 2. リハビリテーション領域での特化したDX

大門恭平が理学療法士としての専門知識を活かす領域です。

**従来のリハビリテーション業務の課題：**

1. **患者の回復プロセスが「見えない」**
   - リハビリの効果を数値化していない
   - 患者が「自分は少しでも良くなっているのか」と疑問に思う
   - モチベーション低下 → リハビリ継続率低下 → 効果減少の悪循環

2. **リハビリ効果の測定が属人的**
   - 理学療法士個人の判断に依存
   - 「この患者の回復は早いね」「あの患者は遅いね」と比較できない
   - 最適なプログラムの設計ができない

3. **スタッフの疲弊**
   - 同じ動作の繰り返し
   - 進捗測定のための手作業が多い
   - データ入力・報告書作成に時間を費やす

**DXによる改善方法：**

```
従来のリハビリ：
患者の動作 → セラピストの観察 → セラピストの記憶 → 主観的判断

DXによるリハビリ：
患者の動作 → ウェアラブルセンサー → データ収集
         ↓
患者のグラフ・動画化 → AI分析による最適プログラム提案
         ↓
患者へのフィードバック → モチベーション向上
         ↓
セラピストの負担軽減 → 患者対応時間増加
```

**具体的なテクノロジー活用：**

| 技術 | 従来の課題 | 改善内容 |
|------|----------|---------|
| **ウェアラブルセンサー** | 動作の定量化ができない | 骨の位置、筋肉の張力をリアルタイムで計測 |
| **データ可視化** | グラフがない | 日々の回復を患者がグラフで確認できる |
| **3D映像化** | 文字だけの説明 | 患者の動きを3Dで自分自身に見せることができる |
| **AI分析** | セラピスト個人の判断 | 患者ごとに最適なリハビリプログラムを自動提案 |
| **遠隔リハビリ** | 医療機関への通院が必須 | 自宅でのリハビリ実施・リモート指導が可能 |

#### 3. 医療機関スタッフの働き方改革

医療従事者（看護師・理学療法士・事務職など）の過酷な労働環境を改善することも医療DXの重要な要素です。

**課題：**
- 長時間労働が常態化（特に看護師は月平均60時間以上の残業）
- 記録・報告業務が膨大（患者対応の時間が不足）
- デジタルリテラシーが低い世代が多い

**DXによるアプローチ：**
- 業務自動化ツール（RPA）の導入 → 定型的な業務を自動化
- クラウドベースの情報共有システム → 紙ベースの記録を廃止
- スタッフ向けデジタルトレーニング → リテラシー向上
- テレワーク対応 → 自宅での業務実施が可能に

**実現される効果：**
- 医療スタッフの負担軽減
- スタッフの離職率低下
- 若い世代の医療職志望者増加
- 医療の質の向上

### 医療機関経営とDX：ビジネスモデルの転換

大門恭平の医療DX推進は、実は**医療機関の経営モデル自体を転換させる試み**です。

**従来の医療機関のビジネスモデル：**
```
診療報酬（固定） > 診療コスト（増加） = 医業赤字
↓
経営を救うには、オプション収入（予防医療、自由診療など）が必須
```

**DXによる新しいビジネスモデル：**
```
診療報酬（固定） + デジタル化による業務効率化
↓
同じ診療報酬でも、コストを大幅削減
↓
本来の医療に集中できる環境の創出
```

さらに、DXにより以下の新規事業機会も生まれます：

1. **遠隔医療・オンライン診療** — 地方の患者向けサービス
2. **ウェアラブル・ヘルステック製品** — 企業向け予防医療ソリューション
3. **医療データ分析サービス** — 医療機関向けコンサルティング

## Part 3：人生の危機が変えた視点——小児がんの経験

### 2022年5月：長男の診断

**人生が急激に変わった日**

大門恭平の長男（当時9歳）が小児脳腫瘍（脳幹グリオーマ）と診断されました。

医師から告げられた言葉：
> 「この病気に対して、効果的な治療法がありません」

#### その時の状況

- 医学知識を持つ医療従事者でさえ、この診断は絶望的だった
- 医師が「治療法がない」と言った時点で、多くの患者家族はそこで終わり
- しかし、大門恭平は違う決断をした

### 医療従事者が患者家族に転じた時に見えたこと

医師から「治療法がない」と告げられた瞬間、大門恭平は**医療システムの根本的な問題**に直面します。

#### 問題1：医学知識の限定性

地元の医師が「治療法がない」と言ったとしても、それは：
- **「自分の知識や経験の中に治療法がない」という意味であって**
- 「世界的に治療法が存在しない」という意味ではない

小児脳腫瘍のような希少疾患では：
- 年間患者数が100人未満
- 大学病院でも年に数人程度の症例
- 一般的な医師には治療経験がない

#### 問題2：医学情報へのアクセスの不平等

ここで、大門恭平の**医学知識と医学文献検索スキル**が生命線になります。

**医学知識を持つ人がすること：**
1. PubMedなどの医学文献データベースを検索
2. 「脳幹グリオーマ」「BRAF変異」「ダブラフェニブ」などのキーワードで論文を探索
3. 国際的な臨床試験データを発見
4. 複数の医師にセカンドオピニオンを求め、「この治療は可能か」と具体的に質問
5. 高リスク医学判断を行う（9時間の脳幹生検手術の実施）
6. 北海道大学の臨床試験に参加

**医学知識を持たない人の現実：**
1. 医師の言葉「治療法がない」を信じるしかない
2. インターネットで「脳腫瘍 治療」と検索しても、信頼できる情報にたどり着きにくい
3. セカンドオピニオンを求めるという選択肢を思いつかない
4. 結果として、医師の判断が「絶対」となる

#### 医学情報アクセスの階層構造

```
第1層：医学知識なし（一般患者・患者家族）
  ↓
  医師の判断のみに依存
  ↓
  「治療法がない」で終わり

第2層：基礎的な医学知識（医療従事者レベル）
  ↓
  医学文献を検索できる
  ↓
  複数医師に相談できる
  ↓
  国際的な臨床試験にアクセス可能

第3層：高度な医学知識（医学者・研究者）
  ↓
  最新の研究動向を把握
  ↓
  臨床試験の設計に関与
```

**大門恭平は、第2層の知識を活用することで、息子の命を救いました。**

### 治療から回復へ：データが示す希望

大門恭平が行った医学的判断と決断：

| 時期 | 出来事 |
|------|--------|
| **2022年5月** | 診断確定。医師から「治療法がない」と告知 |
| **2022年6月** | 医学文献の系統的な調査開始。「寝る間も惜しんで」調べる |
| **2023年6月** | 北海道大学の臨床試験に参加決定。ダブラフェニブ・トラメチニブ療法開始 |
| **2023年11月** | 小児への保険適用が承認される |
| **2024年6月** | 患児が「自転車に乗ったり走ったりできる」まで回復 |

**この回復がもたらしたもの：**

1. **個人的な幸福** — 息子の命が救われた
2. **医療体制への貢献** — 臨床試験データが、その後の小児患者全体への保険適用を実現
3. **医療システムへの問い直し** — 「医学知識を持つ家族だけが救われる」という構造的不公正の可視化

### 社会への発信：医学知識の民主化へ

大門恭平は、この経験を決して個人的な悲劇のまま終わらせませんでした。

#### 複数のメディアでの情報発信

**1. note での詳細記事**
- 記事タイトル：「子供に脳腫瘍があるとわかったとき」
- 内容：医学的な知見、意思決定プロセス、治療経過の詳細
- 対象：同じ状況にある患児家族、医療関係者

**2. ベネッセ「たまひよ」での体験談**
- より一般向けの形式で、患児家族への情報提供
- 「医学探索の方法」「医師への相談方法」などの実用的なアドバイス
- **他の患児家族が「治療法がない」で絶望するのを防ぐ**

**3. Doctorbook での医師向け発信**
- 医学的な観点から、臨床試験の重要性を啓発
- 医師に対して、「患者や家族による医学探索」という新しい医療現象を提示

**4. Twitter/X での継続的な発信**
- リアルタイムでの医学知識の翻訳
- 他の患児家族からの質問への回答
- 医療情報の双方向的な交換

#### 発信が持つ社会的価値

**「医学知識を持つ家族だけ救われる」という構造を壊すこと**

大門恭平の発信は、医学知識を持たない他の患児家族に対して：

```
従来：
患児家族 → 医師の言葉「治療法がない」 → 絶望 → 諦め

大門恭平の発信後：
患児家族 → 医学探索の方法を学ぶ → 「治療法があるかもしれない」
        → 複数医師に相談 → セカンドオピニオン取得
        → 臨床試験への参加機会発見 → 治療にたどり着く
```

## Part 4：統合的なビジョン——医療DXと患者エンパワーメント

### 見えてくる共通のテーマ

ここまで、大門恭平の2つの活動を別々に説明してきました：

1. **組織内での医療DX推進** — SDX研究所での医療機関のデジタル化
2. **社会への患者エンパワーメント発信** — 小児がん患児家族への医学情報提供

しかし、この2つは実は**同じ根本的な問題の異なるアプローチ**です。

その根本的な問題とは：

### **「医療情報とテクノロジーへのアクセスの不平等」**

医療DX推進で実現しようとしていること：
```
医療機関内での情報の民主化
├─ 患者データの可視化：セラピストも医師も同じ情報にアクセス可能
├─ リハビリ効果の定量化：患者も回復プロセスを「見える」状態に
└─ スタッフの負担軽減：情報共有により、より患者に向き合う時間を確保
```

患者エンパワーメント発信で実現しようとしていること：
```
患者家族への医学情報の民主化
├─ 医学知識のない家族でも、医学文献にアクセスする方法を知る
├─ セカンドオピニオンの文化：医師の判断が「絶対」ではないことを理解
└─ 臨床試験への参加機会の可視化：「治療法がない」ではなく、「まだ知られていない治療法」を探す
```

**この2つを統合した視点：**

```
医療機関のデジタル化（医療DX）
    ↓
医療スタッフが効率的に、患者中心医療を実現
    ↓
患者への情報提供が充実する
    ↓
患者が自分の治療を主体的に選択できるようになる
（患者エンパワーメント）
```

### 医療DXが本来目指すべき方向

医療DXは、しばしば「システムの効率化」「コスト削減」として語られます。

しかし、大門恭平の実践が示しているのは：

**医療DXの本来の目的は、「患者が自分の治療について主体的・自立的に決定できる環境を作ること」**

具体的には：

| 従来の医療 | 医療DX後の医療 |
|-----------|--------------|
| 患者データ = 医師・医療機関の情報資産 | 患者データ = 患者自身が理解・活用すべき情報 |
| 医師の判断が「絶対」 | 患者による複数医師への相談・セカンドオピニオンが容易 |
| 患者は「医師が教えてくれることだけ」を知る | 患者が医学情報に直接アクセス可能 |
| 希少疾患の患者は「治療法がない」で終わり | 国際的な臨床試験への参加機会が可視化される |

### 3つのレベルでの「民主化」

大門恭平の活動を統合的に理解するには、3つのレベルでの医療情報の民主化を認識することが重要です：

#### レベル1：医療機関内での民主化（医療DX推進）

**場所**: 医療法人生和会グループ内

**実現方法**:
- ウェアラブルセンサーによるデータ収集
- 患者向けダッシュボード（リハビリの進捗を患者が見える形に）
- スタッフ向けの情報共有システム
- AI による最適プログラム提案

**実現される価値**:
- 患者のモチベーション向上
- スタッフの負担軽減
- より質の高い医療提供

#### レベル2：患者・医療従事者間での民主化（患者エンパワーメント発信）

**場所**: SNS、note、メディア

**実現方法**:
- 医学知識の翻訳・提供
- 「医学探索の方法」の教示
- 臨床試験情報の共有
- セカンドオピニオン文化の啓発

**実現される価値**:
- 医学知識を持たない患者家族が、自分の治療を主体的に選択
- 希少疾患でも「治療法を探す」という選択肢が生まれる
- 患者による医学探索 → 臨床試験参加 → 医療体制全体への改善

#### レベル3：医療システム全体での民主化（長期的な展望）

**目指すべき未来**:
- AI による医学論文の一般向け翻訳
- 患者向けの医療意思決定支援システム
- 臨床試験参加への障壁低下
- 患者・医師が対等な関係で医療意思決定を行える環境

## Part 5：現在と今後：医療改革に向けた段階的推進

### 現在の活動：内部での実績構築と社会への発信の並行

大門恭平が現在行っていることは、決して散発的ではなく、**長期的な医療改革に向けた段階的な推進**です。

#### 組織内（セイワ会グループ）での実績構築

**短期目標（1-2年）:**
- リハビリテーション領域での「患者データの可視化」実装
- ウェアラブルセンサー導入の拡大
- 18人のセラピストを配置した関西9病院での DX推進事例蓄積

**中期目標（3-5年）:**
- セイワ会グループでの DX推進の具体的成果をケーススタディ化
- 他の医療法人への DX コンサルティング展開
- 医療機関経営の「新しいモデル」として業界で認知される

#### 社会への発信と患者エンパワーメント

**現在進行中:**
- SNS（Twitter/X @KyoheiOmon）での医学情報発信
- note での詳細な患者・医療情報の記事
- 小児がん患児家族ネットワークへの参加
- メディアでの講演・インタビュー

**今後の展開:**
- 患者向けの医学情報ポータルサイト開発への関与
- セカンドオピニオン文化の社会的啓発
- 医療情報の民主化に関する著作出版

### 長期ビジョン：医療システム全体の改革

大門恭平の活動が最終的に目指しているのは、**日本の医療システムそのものの転換**です。

#### 1. 医学知識の民主化

**現状の問題:**
- 医学知識は医師・医療従事者の独占物
- 患者は「医師が教えてくれること」だけを知る
- 特に希少疾患では、医師自身も十分な知識を持たない

**目指すべき未来:**
- AI による医学論文の自動翻訳・要約
- 患者向けの医療情報ポータルサイト
- 学校教育での基礎医学知識の提供
- 患者が医学情報に直接アクセス可能な環境

#### 2. 患者による医療意思決定の制度化

**現状の問題:**
- 医師の判断が「絶対」
- 患者の選択肢は制限される
- 特に、医師の知識外の治療法は見つからない

**目指すべき未来:**
- セカンドオピニオン・セカンドピアオピニオン（同じ専門性を持つ複数医師への相談）の制度化
- 臨床試験への患者参加障壁の低下
- 患者による医療意思決定を医療体制に組み込む

#### 3. 医療DXの目的の転換

**現在の医療DX:**
- 医療スタッフの効率化が主目的
- 患者側の利益は「副次的」

**大門恭平が目指す医療DX:**
- 患者中心医療（Patient-Centered Care）への転換
- 患者体験と患者主体性の向上が主目的
- 医療スタッフの効率化は、患者対応充実のための手段

#### 4. 希少疾患患者への対応

**現在の問題:**
- 患者数が少ないため、医学研究の優先度が低い
- 医師の経験が不足
- 臨床試験が限定的

**目指すべき未来:**
- 国による希少疾患研究への直接投資
- グローバルな臨床試験ネットワークの構築
- インターネットを通じた患者家族による医学探索の支援体制

## Part 6：大門恭平から学べること

### 1. 複数の専門領域を統合することの力

大門恭平が成し遂げたことは、**医療 + デジタル + 患者視点**という3つの領域の統合です。

```
医療
 ↑
 ├── 医療従事者としての実務知識
 ├── 患者と向き合うことで知る「医療の現実」
 └── 小児がん経験による患者家族の視点

デジタル
 ↑
 ├── デジタルハリウッド大学院での系統的学習
 ├── データ分析・可視化・AI 技術の理解
 └── テクノロジーが医療に何をもたらすかの洞察

患者視点
 ↑
 ├── 息子の小児脳腫瘍という家族の危機
 ├── 医学情報アクセスの不平等を肌で感じる
 └── 「医学知識を持つ家族だけが救われる」という不公正の認識
```

この統合がなければ：
- 医療職だけなら、テクノロジーの価値を理解しない
- IT職だけなら、医療の現場課題を理解しない
- 患者視点がなければ、医療DXの目的が「効率化」で終わる

### 2. 個人的な危機が社会的な使命に転換される

大門恭平にとって、息子の小児脳腫瘍は個人的な悲劇でした。

しかし、彼はこの経験を：
- 医療システムの問題提起へ
- 他の患児家族への支援へ
- 医学知識の民主化への推進力へ

と転換させました。

**これは決して特殊な例ではなく、社会的な課題意識を持つ人間にとって必要な思考様式です。**

### 3. 組織内の実績と社会への発信を並行させること

大門恭平は、セイワ会グループ内での DX推進と、SNS・note での患者エンパワーメント発信を並行しています。

この2つは相互に強化し合っています：

```
組織内での実績
 ↓
「医療DXで本当に患者体験が変わるのか」を実証
 ↓
社会への説得力が増す
 ↓
SNS・note での発信がより信頼される
 ↓
患者家族からの質問・相談が増える
 ↓
組織内での改善がより加速される
```

### 4. 「患者エンパワーメント」を医療DXの本質に位置付けること

多くの医療 DX は、「システムの効率化」「コスト削減」として語られます。

しかし、大門恭平の視点は異なります：

**医療DX とは、患者が自分の治療について主体的・自立的に決定できるようにするための手段である**

これは医療改革としてのパラダイムシフトを意味します。

## 結論：医療の民主化と患者エンパワーメント

大門恭平の人生と活動を統合的に見ると、浮かび上がってくるのは：

**医療情報とテクノロジーへのアクセスの民主化**

この課題は：

- **個人的なレベル** — 医学知識を持つ患者家族が、医学知識を持たない患者家族を助けることができる
- **医療機関レベル** — DXにより、患者データを「患者自身が理解・活用できる」情報に変換できる
- **医療システムレベル** — 患者による医療意思決定が、医療体制全体の改善につながる

大門恭平は、自分の職業的キャリアと個人的な経験を通じて、この課題に正面から取り組んでいます。

彼の実践が示しているのは、**医療の民主化と患者エンパワーメントは、医療DXの単なる「副産物」ではなく、本質である**ということです。

その実現に向けた道のりはまだ長いですが、確実に進行しています。
