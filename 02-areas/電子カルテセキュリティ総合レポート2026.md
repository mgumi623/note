# 病院の電子カルテシステム：セキュリティ総合調査レポート 2026

## レポートの目的と構成

本レポートは、病院の電子カルテシステムを取り巻くセキュリティの全体像を、**インフラ構成**・**データ管理**・**攻撃事例**・**防御策**の4つの観点から包括的にまとめたものです。

4名の調査員による並行調査＋ファクトチェックを経て作成しました。

---

## エグゼクティブサマリー

### 5つの核心的ファインディング

1. **VPN機器の脆弱性が最大の侵入経路**：国内で発生した主要な病院サイバー攻撃の大半がVPN装置（特にFortiGate）の既知の脆弱性を突いた侵入。パッチ未適用が根本原因。

2. **サプライチェーン攻撃が新たな脅威**：大阪急性期・総合医療センター（2022年）では給食委託業者経由で侵入された。病院本体のセキュリティだけでは防げない。

3. **被害額は年々急増**：半田病院の約2億円（2021年）→ 大阪急性期の和解金10億円（2022年）→ Change Healthcareの2,200億円超（2024年）。攻撃者も大規模化している。

4. **閉域網神話の崩壊**：「インターネットに繋がっていないから安全」は完全に過去の話。VPN、リモートメンテナンス、委託業者接続など外部との接点が必ず存在する。

5. **法的義務化が急速に進行**：2023年4月に医療法施行規則でサイバーセキュリティ確保が義務化。2027年度までに多要素認証（MFA）の導入が求められている。

## 第1部：電子カルテシステムの仕組み

### 1. ネットワーク構成

病院のネットワークは、一般企業とは根本的に異なる設計思想で構築されています。

#### 三層分離の基本構造

```
┌─────────────────────────────────────────────┐
│           病院ネットワーク全体像              │
│                                              │
│  [インターネット]                            │
│       │                                      │
│  [ファイアウォール/UTM]                      │
│       │           │                          │
│     [DMZ]    [VPN装置]                       │
│    Web/メール  ├ ベンダー保守用              │
│               ├ 拠点間接続                   │
│               └ クラウド接続                 │
│                                              │
│  [コアスイッチ(L3)]                          │
│       │                                      │
│    ┌──┼──┬──┬──┬──┐                        │
│    HIS 医療 情報 ゲスト VoIP                 │
│    系  機器 系   Wi-Fi  系                   │
│    │   系   │     │     │                   │
│   電子  CT  事務  患者  IP電話              │
│   カルテ MRI PC   端末  ナースコール        │
│   サーバー 等  メール   等                   │
│                                              │
└─────────────────────────────────────────────┘
```

| ネットワーク層 | 接続するシステム | インターネット接続 |
|--------------|----------------|------------------|
| **HIS系（医療情報系）** | 電子カルテ、オーダリング、医事会計、PACS | **完全分離** |
| **情報系（事務系）** | メール、グループウェア、経営管理 | 制限付き接続 |
| **インターネット系** | Web閲覧、患者Wi-Fi | 接続あり |

この3系統をVLAN（仮想LAN）で論理的に分離し、相互の通信をファイアウォールで制御するのが基本設計です。

#### 主要なセキュリティ機器

| 機器 | 市場シェア1位 | 役割 |
|-----|------------|------|
| ファイアウォール/UTM | Fortinet FortiGate（約34.7%） | 通信の許可/遮断、複合的な脅威防御 |
| VPNゲートウェイ | FortiGate、Cisco ASA | 拠点間接続、リモートメンテナンス |
| ネットワークスイッチ | APRESIA、Allied Telesis | VLAN構成、ネットワーク分離 |

#### 閉域網サービス

病院間データ共有やクラウド型電子カルテの接続には、通信事業者の閉域網サービスが使われます。

- **NTT**: フレッツ・VPNワイド、VPNプライオ、VPNアドバンス
- **KDDI**: KDDI WVS（Wide Area Virtual Switch）

これらはインターネットを経由しないため安全性が高いが、コストも高額です。

> **詳細**: [[電子カルテシステムのネットワーク構成]]

### 2. データベース構成

#### 主要電子カルテベンダーとDB

| ベンダー | 主要製品 | 使用DB | 対象規模 |
|---------|---------|--------|---------|
| 富士通Japan | HOPE LifeMark-HX | Oracle Database | 大規模病院（シェア約35%） |
| NEC | MegaOakHR | Oracle / PostgreSQL | 大中規模病院 |
| ソフトウェア・サービス | e-カルテ | ― | 中規模病院 |
| エムスリーデジカル | デジカル | クラウドDB | 診療所（クラウド型） |

#### データの種類と保存

- **構造化データ**（検査値、処方情報）→ RDBMS（Oracle、SQL Server等）+ SAN
- **医用画像**（CT、MRI）→ DICOM形式 → PACS + NAS
- **標準化データ**→ SS-MIX2（HL7 V2.5形式）
- **外部共有**→ HL7 FHIR（2025年より順次運用開始）

#### 暗号化の現状

| 暗号化の種類 | 実施状況 |
|------------|---------|
| 保存時暗号化（TDE等） | 大規模病院では進展、中小は未実施多数 |
| 通信時暗号化（TLS 1.2+） | 院内通信は平文のケースも残存 |
| 可搬媒体の暗号化 | 「いまだ道半ば」の状態 |

#### バックアップの3-2-1ルール

- **3**: データのコピーを3つ持つ
- **2**: 2種類の異なるメディアに保存
- **1**: 1つはオフサイト（遠隔地）に保管

しかし、HIPAA Journalの調査によると遵守率は**わずか約20%**です。

## 第2部：サイバー攻撃の実態

### 3. 国内の主要マルウェア感染事例

#### 時系列一覧

| 年月 | 病院 | ランサムウェア | 侵入経路 | 復旧期間 | 被害規模 |
|------|------|------------|---------|---------|---------|
| 2018年10月 | 宇陀市立病院（奈良県） | GandCrab | 不明（導入直後） | 約5か月 | 1,133人分のカルテ暗号化 |
| 2021年10月 | **半田病院（徳島県）** | LockBit 2.0 | **FortiGate VPN脆弱性** | 約2か月 | 約2億円、8.5万人分のカルテ |
| 2022年10月 | **大阪急性期・総合医療センター** | ― | **サプライチェーン攻撃**（給食業者VPN→RDP） | 約2.5か月 | 和解金10億円、逸失利益数十億円 |
| 2024年5月 | 岡山県精神科医療センター | ― | VPN脆弱性 | ― | 最大4万人分の情報がダークウェブへ流出 |
| 2026年2月 | 日本医科大武蔵小杉病院 | ― | 医療機器保守用VPN | 調査中 | 約1万人分の情報漏洩、身代金152億円要求 |

#### 半田病院（2021年）の教訓

半田病院の事例は、日本の病院セキュリティの問題を象徴的に示しています。

**なぜ起きたのか**：
- VPN装置（FortiGate 60E）の脆弱性（CVE-2018-13379）は2019年にパッチが公開されていたが、**約2年間適用されていなかった**
- マルウェア対策ソフト、Windows Update、Windowsファイアウォールが**いずれも無効化されていた**
- 理由：「セキュリティソフトが電子カルテの動作を遅くする」というベンダー判断

これは「セキュリティ vs 利便性」のトレードオフではなく、**基本的な対策の放棄**です。

#### 大阪急性期・総合医療センター（2022年）の教訓

この事例の最大のポイントは「サプライチェーン攻撃」です。

**攻撃の流れ**：
```
攻撃者
  ↓ CVE-2018-13379を悪用
給食委託業者（ベルキッチン）のVPN装置
  ↓ 認証情報を窃取
RDP接続で病院ネットワークに侵入
  ↓ 全サーバーのパスワードが共通
Active Directory経由で全システム掌握
  ↓
ランサムウェア実行（電子カルテ暗号化）
```

**根本原因**：
- 全ユーザーに管理者権限（Administrator）が付与
- 全サーバーでパスワードが共通
- 給食業者と病院のネットワークが未分離

### 4. 攻撃手法の分類

#### 4-1. 初期侵入の手法

| 手法 | 概要 | 関連事例 |
|------|------|---------|
| **VPN脆弱性の悪用** | VPN装置の未修正脆弱性を突いて侵入 | 半田病院、大阪急性期、岡山精神科、武蔵小杉 |
| **サプライチェーン攻撃** | 委託業者経由で間接的に侵入 | 大阪急性期（給食業者） |
| **フィッシングメール** | 悪意ある添付ファイルで感染 | アイルランドHSE（Excel添付） |
| **RDPの悪用** | 公開されたリモートデスクトップに侵入 | 複数の事例で攻撃の「橋渡し」 |
| **物理持ち込み** | 感染した私物PCを院内接続 | 福島県立医大 |

#### 4-2. 内部展開（ラテラルムーブメント）

侵入後、攻撃者はActive Directory（AD）の管理者権限を奪取して全システムを掌握します。

1. Mimikatz等でメモリ上のパスワードハッシュを窃取
2. Pass-the-Hash攻撃で他サーバーに認証
3. 段階的に権限昇格 → ドメイン管理者を奪取
4. 全システムにランサムウェアを展開

#### 4-3. 二重脅迫（ダブルエクストーション）の常態化

現在のランサムウェア攻撃の**96%がデータ窃取を伴う**二重脅迫型です（2024年、Arctic Wolf調査）。

1. **暗号化**：「復号したければ身代金を払え」
2. **データ公開**：「払わなければ盗んだ患者データをダークウェブに公開する」

さらに、Change Healthcareの事例では身代金を支払ったにもかかわらず、実行犯が別グループに移って再度脅迫する「三重脅迫」まで発生しました。

#### なぜ病院が狙われるのか

| 理由 | 説明 |
|------|------|
| **人命への直結性** | システム停止=患者の生命リスク → 身代金を払いやすい |
| **レガシーシステム** | Windows XP/7がまだ稼働、医療機器のOS更新は薬事法で制約 |
| **セキュリティ投資不足** | 医療機器や人件費が優先、IT人材も不足（42%が専門家不足を報告） |
| **24/365稼働** | パッチ適用のためのメンテナンス時間が取れない |
| **医療データの高価値** | 病歴は変更不可能で、ダークウェブで高値取引 |

## 第3部：防御策と法規制

### 5. ガイドラインと法規制の全体像

```
┌──────────────────────────────────────────────────┐
│  第1層：法規制（法的義務）                          │
│  医療法施行規則（2023年4月〜）                      │
│  個人情報保護法（要配慮個人情報）                    │
│  次世代医療基盤法                                  │
├──────────────────────────────────────────────────┤
│  第2層：ガイドライン（事実上の義務的基準）            │
│  厚労省ガイドライン第6.0版（2023年5月〜）           │
│  3省2ガイドライン                                  │
├──────────────────────────────────────────────────┤
│  第3層：組織体制                                   │
│  CSIRT、BCP、医療ISAC                             │
├──────────────────────────────────────────────────┤
│  第4層：技術的対策                                 │
│  EDR、MFA、PAM、ゼロトラスト、                     │
│  マイクロセグメンテーション                         │
└──────────────────────────────────────────────────┘
```

#### 厚労省ガイドライン第6.0版（2023年5月）

**4編構成**で対象読者ごとに整理：

| 編名 | 対象 | 主な内容 |
|------|------|---------|
| 概説編 | 全関係者 | 全体構成と前提となる考え方 |
| 経営管理編 | 病院長・理事長 | セキュリティへの経営責任、予算確保 |
| 企画管理編 | 情報部門責任者 | リスクアセスメント、委託管理 |
| システム運用編 | IT技術者 | 技術的対策の実装、日常運用 |

**主な要求事項**：
- **ゼロトラスト**の概念を導入（境界防御だけでは不十分）
- **2027年度までに多要素認証（MFA）** の導入
- サイバー攻撃を想定した**BCP策定**

#### 医療法施行規則の改正（2023年4月施行）

すべての病院・診療所・助産所に「サイバーセキュリティを確保するために必要な措置を講じる」ことが**法的義務**となりました。

#### 日本 vs 米国（HIPAA）の比較

| 項目 | 日本 | 米国（HIPAA） |
|-----|------|-------------|
| MFA | 2027年度までに導入（ガイドライン推奨） | 2026年頃に義務化予定（法的義務） |
| 暗号化 | ガイドラインで推奨 | 義務化予定 |
| 違反時の罰則 | 立入検査での指導（罰則弱い） | 高額課徴金（数百万ドル） |
| 年次監査 | 義務化されていない | 義務化予定 |

日本は米国に比べて法的強制力が弱い点が課題です。

### 6. 具体的なセキュリティ対策技術

| 技術 | 概要 | 導入状況 |
|------|------|---------|
| **EDR** | 端末の挙動を監視し未知の攻撃も検知 | 大規模病院で進展、中小は不足 |
| **MFA** | パスワード＋ICカード/生体認証 | 2027年度の期限に向け導入中 |
| **PAM** | 管理者アカウントの厳格管理 | 特権侵害が全侵害の35%を占める |
| **ゼロトラスト** | すべてのアクセスを都度検証 | ガイドラインで推奨、導入は初期段階 |
| **マイクロセグメンテーション** | 個々のデバイスレベルで通信制御 | 先進的病院で導入開始 |
| **SOC/MDR** | 24時間のセキュリティ監視 | 外部委託（MSS）が主流 |
| **IDS/IPS** | 不正通信の検知/自動遮断 | UTMに統合される形で普及 |

## 第4部：まとめと提言

### 事例が示す共通パターン

すべての攻撃事例を横断的に分析すると、以下のパターンが浮かび上がります。

```
VPN機器の脆弱性放置 ──→ 外部から不正侵入
         ↓
パスワードの使い回し ──→ 横展開（ラテラルムーブメント）
         ↓
管理者権限の過剰付与 ──→ 全システム掌握
         ↓
バックアップの不備 ──→ 復旧困難（数か月の停止）
         ↓
   莫大な被害額（数億〜数千億円）
```

### 医療機関が今すぐ取り組むべきこと

#### 最優先（2026年中）

1. **VPN装置のファームウェア更新** → 全攻撃の最大の侵入口
2. **多要素認証（MFA）の導入計画** → 2027年度期限
3. **オフラインバックアップの確保** → ランサムウェア耐性の要
4. **サプライチェーンのセキュリティ評価** → 委託業者経由の侵入を防ぐ
5. **BCP（サイバー攻撃対応版）策定** → 法的義務

#### 中期的に推進

6. EDRの全端末展開（MDRサービスの活用も検討）
7. ネットワークのマイクロセグメンテーション
8. 特権アクセス管理（PAM）の導入
9. インシデント対応訓練（年1回以上）

#### 継続的に実施

10. 職員へのセキュリティ教育（特にフィッシング対策）
11. 医療ISACへの参加と情報共有
12. ガイドラインの最新版への継続対応

### 被害額の推移が示す警告

| 年 | 事例 | 被害額 |
|----|------|--------|
| 2018 | 宇陀市立病院 | 限定的 |
| 2021 | 半田病院 | 約2億円 |
| 2021 | アイルランドHSE | 推定880億円 |
| 2022 | 大阪急性期 | 和解金10億円＋逸失利益数十億円 |
| 2024 | Change Healthcare | 2,200億円超 |
| 2026 | 武蔵小杉病院 | 身代金152億円要求（調査中） |

被害額は指数関数的に増大しています。「自分の病院は大丈夫」は最も危険な思い込みです。
