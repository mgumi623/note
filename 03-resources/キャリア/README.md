## 主要な発見（ハイライト）

### 🔴 人件費率が最も高い業種
1. **医療：50～54%** - 医業経営全体で半分以上が人件費
2. **飲食：20～43.5%** - 実態が目安を大幅に上回る
3. **不動産：30～45%** - 営業職中心の経営モデル
4. **情報通信：30.7%** - ホワイトカラー中心で高い

### 🟢 人件費率が最も低い業種
1. **流通・卸売：7.0%** - 業界で最も効率的
2. **小売：13.3～18%** - 非正規職員で対応
3. **製造：20.7%** - 中程度（産業別で幅あり）

### 📊 給与格差が最も大きい業種
1. **小売：3～5倍** - 店長 vs パート
2. **飲食：2.5～3.5倍** - 店長 vs パート
3. **自治体：2.4～2.7倍** - 医師 vs 一般行政職
4. **医療：2.06倍** - 医師 vs 看護師

### 🌍 日本と海外の人件費比較
- **日本：31.27ドル/時間** = G7最低
- **ドイツ：57.12ドル** = 日本の1.8倍
- **米国：49.25ドル** = 日本の1.6倍
- **問題**：「低人件費・低生産性」の悪循環

### 📈 2025年の給与上昇トレンド
- **医療**：診療報酬3.09%↑で人件費急増見込み
- **建設**：標準労務費導入で人件費強制引き上げ（2025年12月）
- **情報通信**：AI人材不足で給与高騰継続
- **飲食**：最低賃金引き上げで利益圧迫

### 🤖 AI・DX導入による職種の未来
- **需要が増加**：AI・データ科学職、デジタルマーケター、クラウド技術者
- **需要が減少**：定型事務職、データ入力、コンタクトセンター
- **日本の課題**：DX人材不足率85.1%（米独より極度に高い）

- 上場企業有価証券報告書

## 注意事項

1. **データの時点**
   - 統計データは時系列で変動します
   - 最新情報については公式サイトで必ず確認してください
   - このノートは2026年2月17日時点での最新情報です

2. **個別判断について**
   - ここで提供するデータは参考情報です
   - 具体的な給与交渉や採用判断は、企業の経営状況、個人のスキル・経験を加味して慎重に進めてください

3. **業種の分類について**
   - 同じ業種内でも企業規模、地域により大きな差異があります
   - 「業界平均」は参考値であり、個別企業での適用は限定的です

4. **AI・DX予測について**
   - 職種の需要予測は不確実性が高いです
   - 長期キャリア計画では複数シナリオを検討してください
