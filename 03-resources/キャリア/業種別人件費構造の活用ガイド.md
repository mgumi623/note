## 給与交渉での活用

### 1. 転職時の給与交渉

#### ステップ1：現在地の確認

```
自分の状況を整理：
□ 現職の業種
□ 現在の年収
□ 職種・職位
□ 経験年数
□ スキル・資格
□ 転職先の業種
```

#### ステップ2：市場相場の調査

**例1：製造業のエンジニアから情報通信業SEへの転職**

```
現状：
  業種：製造業
  職種：エンジニア
  現在年収：463.4万円
  経験年数：5年

転職先候補：
  業種：情報通信（IT業）
  職種：システムエンジニア（SE）
  市場相場：700～900万円（月額単価70～90万円 × 12月）
  経験年数：転職で5年＋αの扱い

交渉ポイント：
  基準：700万円（市場下限）
  要望：800万円（中位水準）
  根拠：製造業でのエンジニア経験 + IT業の人材不足
```

**例2：金融から医療への転職**

```
現状：
  業種：金融
  職種：営業職
  現在年収：600万円
  経験年数：10年

転職先候補：
  業種：医療
  職種：医療営業（営業職相当）
  市場相場：推定400～550万円（医療業の給与水準に準じる）

交渉ポイント：
  注意：医療業の人件費率が50～54%と極度に高いため、
        金融からの「高給」が維持される可能性は低い
  現実的交渉：500～550万円での妥協を検討
  利点：医療業界内での昇進可能性、専門性の確保
```

#### ステップ3：データに基づいた交渉

```
使用するデータフレーム：

「私のスキルと経験に基づく相場：

  同業種の同職種平均：XXX万円
  （厚生労働省賃金構造基本統計調査より）

  業種転換による調整：
  • 現業種での経験年数による評価：+5%
  • 転職先の人材不足度による上昇：+10%

  提示給与案：XXX万円」
```

#### ステップ4：交渉時の注意点

| 職種 | 交渉のしやすさ | 相場との乖離の許容度 | 備考 |
|------|------|------|------|
| IT・DX人材 | 非常に高い | 大きい（+20～30%も可能） | 供給極度不足で強気交渉可 |
| 医療職（医師除く） | 低い | 小さい（±5%程度） | 人手不足も給与に反映されにくい |
| 建設技能職 | 中程度 | 中程度（+10～15%） | 2025年度で人件費上昇中 |
| 金融営業 | 中程度 | 中程度（±10%） | インセンティブで調整可 |
| 製造エンジニア | 中程度 | 中程度（+5～10%） | 需要増だが供給不足でない |

#### 業種別の昇給相場（年率）

```
医療         2～4%（給与テーブルに依存）
建設         3～6%（給与上昇中）
情報通信     3～6%（市場相場上昇）
製造         1～3%（安定的）
金融         2～4%（成績連動）
自治体       定期昇進＋調整手当
飲食         0～3%（利益に依存）
```

#### 交渉テンプレート：昇給要求

```
「我が部門の人件費率は業界平均の○%で、
 私の職種の市場相場は△万円です。

 現在私の給与は□万円であり、
 業界平均との差分は×万円です。

 今期の昇給を◎%（△万円）を要望します。

 根拠：
 1. 厚生労働省統計による同職種平均（△万円）
 2. 本社のベンチマーク企業との比較（□企業が参考）
 3. 自身の成果実績（▲指標で成果）
 4. 業界の人材採用競争力確保（採用難度が高い）」
```

## 企業側の経営判断

### 1. 適正な人件費率の設定

#### ステップ1：現状分析

```
自社の現状把握：

1. 売上高：＿＿＿＿＿＿円
2. 人件費（給与 + 福利厚生）：＿＿＿＿＿＿円
3. 現在の人件費率：＿＿＿＿＿%
4. 業界平均の人件費率：＿＿＿＿＿%
5. 差分分析：
   □ 高い場合：給与効率を改善が必要か、または価格設定を見直すべきか
   □ 低い場合：人材採用・定着に支障がないか確認
```

#### ステップ2：業種別の適正水準との比較

```
例1：医療法人の場合

現状：
  年間診療報酬（売上）：10億円
  年間人件費：5.5億円
  人件費率：55%

業界平均：50～54%

判定：やや高い → 原因分析が必要
  □ 給与水準が高すぎないか
  □ 職員配置が過剰でないか
  □ 看護師：医師の比率が高いか
  □ 事務職の効率が低いか

対応：
  1. 給与テーブルの見直し（差別的でなく、業界相場との比較）
  2. 職種別の適正配置見直し
  3. 業務効率化の推進（DXなど）
```

```
例2：情報通信企業の場合

現状：
  年間売上：50億円
  年間人件費：18億円
  人件費率：36%

業界平均：30.7%

判定：やや高い → ただし、AI・DX人材の給与上昇を考慮すべき
  □ SE・PG の給与水準が適正か（市場相場：70～90万円/月）
  □ 新卒・中途採用バランスは？
  □ リモートワーク導入で効率化余地がないか

対応：
  1. 高度人材と一般職の給与体系の明確化
  2. 長期育成計画の策定（人材育成投資）
  3. 利益率の向上で人件費率を相対的に低下
```

### 2. 採用予算の策定

#### テンプレート：採用予算計算

```
採用計画：
  新規採用：＿＿人
  既存職員：＿＿人
  総従業員数：＿＿人

採用職種別予算：

職種           人数   平均年収(市場相場)  年間人件費   備考
────────────────────────────────────────────────
SE             5人   800万円            4,000万円   +経営管理費
PG             10人  600万円            6,000万円   +経営管理費
営業           8人   600万円            4,800万円   +インセンティブ
事務           5人   400万円            2,000万円
管理職         2人   1,000万円          2,000万円
────────────────────────────────────────────────
合計           30人  (平均:685万円)     18,800万円

福利厚生・税金加算：
  人件費 18,800万円 × 1.35（福利厚生・税・社保）= 25,380万円

月次人件費：25,380万円 ÷ 12ヶ月 = 2,115万円
```

```
技能職(建) ★★★★      450～    市場相場+15%   育成制度のアピール

```

#### 採用困難度別の対応

**採用困難度が高い職種（AI・SE・医師）**

```
戦略：「相場より高い給与提示」

具体例：AI人材
  市場相場：月額100万円（1,200万円/年）
  推奨提示：月額110～115万円（1,320～1,380万円/年）

  理由：
  1. 採用競争が激化している
  2. スキルの陳腐化が早く、継続学習の支援が必要
  3. 流動性が高いため、初期段階での引き止めが重要
  4. リモートワーク化で、全国から採用競争になっている

その他の施策：
  □ ストックオプション（長期勤続インセンティブ）
  □ 学習支援（年100万円以上の教育投資）
  □ キャリア発展性の明示
  □ プロジェクト選択肢の自由度
```

**採用困難度が低い職種（事務・一般職）**

```
戦略：「相場より低い給与 + 採用広告で補完」

具体例：事務職
  市場相場：350万円
  提示給与：330～340万円

  その代わり：
  □ 勤務の安定性をアピール
  □ DX・効率化で「やりがい」のある業務化
  □ キャリアパス（事務→営業→管理職）の提示
  □ テレワーク制度の充実
  □ 育児・介護支援の充実
```

## 業種別の特殊性と注意点

### 1. 医療業界の特殊性

#### 注意点

```
1. 給与テーブルが法定されている側面
   - 看護師の配置基準によって人員が決まる
   - 診療科目により異なる（精神科は人件費率が高い）
   - 給与は診療報酬に連動している

2. インセンティブが少ない
   - ほぼ定額給与で、業績給がない
   - 昇進による給与上昇が限定的

3. 人手不足の割に給与が上がりにくい
   - 有効求人倍率が2～3倍と極度に高い
   - しかし、給与の相場感は他業種より低い
   - 医師と非医師職の給与差が極度に大きい（2.05倍）

対策：
   □ 医療関連資格（認定看護師など）の取得支援
   □ 給与以外の処遇改善（施設・勤務環境）
   □ キャリアパスの明確化
```

### 2. 情報通信業の特殊性

#### 注意点

```
1. 給与が急速に変動している
   - 市場相場が毎年5～10%上昇中
   - 統計数値（前年度）と現在の相場にズレあり
   - 2025年現在、さらに上昇傾向

2. 職種間での給与差が大きい
   - PM・アーキテクト：高給（132万円/月）
   - プログラマー・保守職：低給（60万円/月）
   - 給与差：2.2倍

3. リモートワークにより地域制限が消滅
   - 全国・全世界が採用競争
   - 東京の相場が全国に波及中

対策：
   □ 市場相場の頻繁な更新（毎四半期推奨）
   □ キャリアパスの明確化（PM→経営層など）
   □ テレワーク制度での競争力を売り込む
   □ 長期育成の考え方を転換（スキルアップ支援）
```

### 3. 建設業の特殊性

#### 注意点

```
1. 改正建設業法で給与が強制的に引き上げられる
   - 2025年12月に「標準労務費」が全面施行
   - 労務費の低減が法的に禁止される
   - 人件費率の上昇が不可避

2. 技能職の高齢化・減少が極度に深刻
   - 技能者がピーク時464万人から303万人へ減少（65.3%）
   - 若手が極度に不足
   - 給与上昇のみでは解決困難

対策：
   □ 長期育成計画の策定（10年単位）
   □ 外国人材の活用検討
   □ 女性技能職の開拓
   □ 自動化・ロボット化への投資
```

### 4. 飲食業の特殊性

#### 注意点

```
1. 人件費率の実態と目安に大きな乖離
   - 目安：25～35%
   - 実態：43.5%（日本政策金融公庫）
   - 差：+8～18.5%の過剰負担

2. 原因分析が急務
   　a. 最低賃金の上昇に経営努力が追いつかない
   　b. 非正規従業員の増加で平均給与が低下（矛盾）
   　c. 営業時間の長さで人員が必要
   　d. 人手不足で給与が高止まり

3. FLコスト（食材費+人件費）が60%を超えている
   - 利益率が極端に低い
   - リスク耐性が低い

対策：
   □ 価格改定による売上増加（原価率改善）
   □ 営業時間・営業日の見直し
   □ セルフサービス化・自動化の推進
   □ メニュー構成の見直し（高粗利商品の比率向上）
   □ スタッフ教育による生産性向上
```

### 5. 小売業の特殊性

#### 注意点

```
1. 給与格差が3～5倍と極度に大きい
   - 店長：45万円（推定月給）
   - パート：15万円（最低賃金層）
   - 差：3倍

2. 非正規職員依存度が50～70%
   - 社員教育が限定的
   - 離職率が高い
   - スキル蓄積が困難

3. セルフレジなどの自動化で事務職が削減中
   - 本社の管理部門で人員削減圧力
   - 店舗運営の高度化（DX）で要求スキル上昇

対策：
   □ 非正規職員の処遇改善（同一労働同一賃金への対応）
   □ キャリアパス（パート→副店長→店長）の明確化
   □ デジタルスキルの育成
   □ 顧客体験向上による売上増（人件費率相対低下）
```

## よくある質問と答え

### Q1: 「現在の年収が市場相場より低い場合、どう交渉すべき？」

**A:** 段階的アプローチを推奨

```
ステップ1：市場相場を複数ソースで確認
  □ 厚生労働省統計
  □ 民間サイト（doda、OpenWork等）
  □ 業界団体のレポート

ステップ2：上司に「市場相場の確認」を打診
  「私の職種の市場相場について情報を共有したいのですが、
   業界の人件費動向から、私の給与を見直すべき時期では
   ないでしょうか？」

ステップ3：具体的な交渉
  「厚生労働省の統計によると、同職種の平均年収は
   ×××万円です。
   現在の私の給与○○万円から△△万円の上昇を
   希望します。」

ステップ4：交渉が難しい場合の判断
  - 外部転職の検討
  - キャリアチェンジの検討
  - スキルアップによる昇進を目指す
```

### Q2: 「給与が下がる業界への転職は？」

**A： 総合的な判断が必要**

```
判定フレームワーク：

総得点 = 給与 × 0.3 + 安定性 × 0.2 + 成長性 × 0.2 + 福利厚生 × 0.15 + やりがい × 0.15

例：金融から医療への転職

        金融      医療      医療の方が優位な理由
─────────────────────────────────────────────
給与    100点    70点      (0.3)
安定性  70点     90点      医師不足で需要確実 (0.2)
成長性  60点     80点      医療業が成長市場 (0.2)
福利厚生 80点    85点      医療業が充実傾向 (0.15)
やりがい 70点    95点      社会貢献度が高い (0.15)
─────────────────────────────────────────────
総得点  75.5     83.75     医療への転職が有利
```

### Q3: 「昇給交渉はいつ、どのようにすべき？」

**A： タイミングが重要**

```
推奨時期：
  □ 評価面談後（成果が数字で明確な時期）
  □ 業績が良い年度末
  □ 異動・昇進のタイミング

避けるべき時期：
  □ 四半期の業績が悪い時期
  □ 会社の経営危機時
  □ 直属上司が多忙な時期

交渉フロー：
  1. 事前打診：「給与について相談させていただきたい」
  2. 時間設定：個別面談の時間を取ってもらう
  3. 提示資料：市場相場の書類を準備
  4. 交渉：冷静に市場相場と自身の価値を説明
  5. 受容：拒否された場合の判断（転職検討）
```

### Q4: 「AI導入で給与が下がるのでは？」

**A： 職種によって大きく異なる**

```
給与が上昇する可能性：
  □ AI導入を推進する職種（PM・データサイエンティスト）
  □ AIの保守・運用職
  □ 創造的業務へのシフト

給与が停滞・低下する可能性：
  □ ルーティン事務職
  □ データ入力・単純事務
  □ 定型営業事務
  □ 初級プログラマー（AIコード自動生成）

対策：
  1. 現在のスキルをAI時代に適応させる
  2. 「AIでは代替できない業務」への移行
  3. 資格取得・スキルアップ
  4. キャリアチェンジの検討
```

### Q5: 「業種別の人件費率が高い企業に就職すると給与が高い？」

**A： 必ずしもそうではない**

```
高い人件費率 ≠ 高い給与

理由：
  1. 人件費率 = 人件費 / 売上 なので、
     人員が多い業種は人件費率が高くなる

  2. 医療業界の例：
     人件費率：50～54%（業界で最高）
     しかし給与水準は他業種より低い傾向
     理由：診療報酬が固定的だから

  3. 小売業の例：
     人件費率：13～18%（業界で低い）
     しかし時間給は最低賃金レベル
     理由：多数の非正規職員がいるから

結論：
  人件費率ではなく、
  ① 平均給与
  ② 給与体系（定額 vs インセンティブ）
  ③ 昇進可能性
  を重視して判断すべき
```

### Q6: 「スタートアップと大企業の給与、どちらが高い？」

**A： 業種と職種に依存**

```
一般的な傾向：

IT業・スタートアップ：
  高給傾向（特にエンジニア）
  理由：人材競争が激しく、ストックオプションもある

医療・建設・製造：
  大企業が高給傾向
  理由：スケールメリット、安定性の価値

金融：
  大手銀行が高給傾向
  理由：給与テーブルが確立している

注意点：
  - スタートアップの「給与+ストックオプション」の価値評価
  - 大企業の「福利厚生・安定性」の価値評価
  - 成長性とリスクのバランス判断
```
