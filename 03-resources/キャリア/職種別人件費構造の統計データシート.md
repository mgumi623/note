## 4. 人件費率の算定式と計算例

### 売上高人件費率の計算式

```
売上高人件費率（%） = 人件費 / 売上高 × 100

例）医療法人の場合：
  年間人件費：5,000万円
  年間診療報酬：10,000万円
  = 5,000万円 / 10,000万円 × 100 = 50%
```

### 給与格差の計算式

```
給与格差倍率 = 高給職種の平均給与 / 低給職種の平均給与

例1）医療：医師 45万円 / 看護師 21.9万円 = 2.05倍
例2）小売：店長 45万円 / パート 15万円 = 3倍
例3）建設：施工管理 632.8万円 / 技能職 400万円 = 1.58倍
```

### 労働分配率の計算式

```
労働分配率（%） = 人件費 / 付加価値 × 100

例）流通業：
  人件費：500万円
  付加価値：1,000万円
  = 500万円 / 1,000万円 × 100 = 50%
```

**注記**：売上高人件費率と労働分配率は異なる概念。
- 売上高人件費率：売上基準
- 労働分配率：付加価値基準

## 10. 参考：統計データ取得方法

### 詳細統計へのアクセス

1. **e-Stat（政府統計の総合窓口）**
   - URL: https://www.e-stat.go.jp/
   - データ：賃金構造基本統計調査（283のデータセット）
   - 検索キー：業種別、職種別、企業規模別、年齢別

2. **厚生労働省統計情報**
   - 賃金構造基本統計調査
   - 医療経済実態調査
   - IT・デジタル人材労働市場調査

3. **総務省統計局**
   - 地方公務員給与実態調査
   - 労働力調査

4. **農林水産省統計**
   - 農業経営統計調査

5. **民間統計**
   - doda（リクルート）：職種別年収
   - 日本政策金融公庫：小企業経営指標
