# なぜ医療業界は賃上げが困難なのか

## はじめに：賃上げ率の衝撃的な格差

2024年の春闘（賃上げ交渉）の結果：

- **医療業界（病院）**: 2.41%
- **他業種平均**: 5.10%

医療業界の賃上げ率は、**他業種の半分以下**です。

なぜこれほどの差が生まれるのか？
それは、医療業界特有の「構造的な制約」があるためです。

このレポートでは、その構造を詳しく解明します。

---

## 賃上げを困難にする5つの構造的要因

### 要因1：診療報酬という「公定価格」の壁

#### 公定価格とは何か

**公定価格とは：**
国（厚生労働省）が全国一律で決める価格のことです。

**医療における公定価格（診療報酬）：**
- 初診料：〇〇円
- 血液検査：〇〇円
- CT撮影：〇〇円
- 入院料（1日あたり）：〇〇円

これらは全て、1点=10円として計算され、**全国どこの病院でも同じ金額**です。

#### 一般企業との決定的な違い

**一般企業（自由価格）の場合：**
```
材料費が上がった → 商品価格を値上げする
人件費が上がった → サービス料金を値上げする
```
→ **企業が自由に価格を決められる**

**病院（公定価格）の場合：**
```
材料費が上がった → 値上げできない（国が決めた価格のまま）
人件費を上げたい → 収入は変わらない
物価が高騰した → 価格転嫁できない
```
→ **病院は価格を自由に決められない**

#### これが意味すること

一般企業なら、コストが上がれば価格に転嫁できます。
しかし病院は、**どれだけコストが上がっても、収入は国が決めた金額のまま**です。

**具体例：**
- 2020年の電気代：月100万円
- 2024年の電気代：月200万円（2倍に高騰）
- 診療報酬：変わらず

→ 電気代が2倍になっても、病院の収入は増えない
→ その分、赤字が拡大する

#### 診療報酬改定の問題点

診療報酬は**2年に1度しか改定されません**。

**改定のタイミング：**
- 2024年4月に改定
- 次は2026年4月（2年後）

**問題：**
この2年の間に物価が急騰しても、収入は据え置きです。

**2026年4月の改定内容：**
- 診療報酬本体部分：3.09%引き上げ
  - 賃上げ対応：1.70%
  - 物価高対応：1.29%

しかし、実際の物価上昇率や他業種の賃上げ率（5.10%）に比べると、**明らかに不十分**です。

---

### 要因2：人件費比率が既に限界に達している

#### 人件費比率とは何か

**人件費比率とは：**
病院の収入（医業収益）のうち、何％を人件費に使っているかを示す指標です。

**計算式：**
```
人件費比率 = 人件費 ÷ 医業収益 × 100
```

**例：**
- 医業収益：10億円
- 人件費：5億円
- 人件費比率：50%

#### 病院の人件費比率の現状

**一般的な基準値：**
- **50%前後が適正**
- **60%を超えると経営が危険**
- **57%が限界**と言われている

**実際のデータ（2024年）：**
- 一般病院（150床規模、黒字）：56.9%
- 看護配置「7対1」の病院：52.2%
- 看護配置「15対1」の病院：58.6%

多くの病院が、すでに**50%台後半**まで達しており、**限界ギリギリ**の状態です。

#### なぜ60%を超えると危険なのか

人件費比率が60%を超えると：

1. **他の経費が払えなくなる**
   - 医薬品費、医療材料費、光熱費、設備投資など
   - これらを合わせると、収入の40%以上必要

2. **赤字が固定化する**
   - 人件費は「固定費」なので、簡単には削減できない
   - 一度60%を超えると、黒字に戻すのが極めて困難

3. **経営の柔軟性が失われる**
   - 患者数が減っても、人件費は変わらない
   - 突発的な出費に対応できない

#### 賃上げの数学的な限界

現在の人件費比率を56%と仮定します。

**5%の賃上げをした場合：**
```
現在の人件費：収入の56%
5%賃上げ後：56% × 1.05 = 58.8%
```
→ まだギリギリ許容範囲内

**10%の賃上げをした場合：**
```
現在の人件費：収入の56%
10%賃上げ後：56% × 1.10 = 61.6%
```
→ **危険水域の60%を超える**

**他業種並みの5.10%の賃上げをするには：**
人件費比率が58.8%になるため、ほぼ限界に達します。
そして、すでに赤字の病院（74.6%）では、**賃上げする余裕がゼロ**です。

---

### 要因3：既に深刻な赤字状態

#### 赤字病院の割合

[[日本の病院経営の課題]]でも説明しましたが：

- **医業赤字の病院：74.6%**
- **経常赤字の病院：65.6%**

つまり、**4つの病院のうち3つが赤字**です。

#### 赤字なのに賃上げができるのか？

答えは「できない」です。

**なぜか：**
- すでに支出が収入を上回っている
- 賃上げすれば、赤字がさらに拡大する
- 借入金や内部留保を取り崩して耐えている状態

**具体例：**
ある病院の状況（年間）：
- 医業収益：10億円
- 医業費用：10億7,460万円
- 医業赤字：7,460万円

この病院が5%の賃上げをすると：
- 人件費増加：約2,500万円（人件費5億円の5%）
- 赤字拡大：7,460万円 → 約1億円

→ 赤字がさらに悪化し、経営破綻に近づく

#### 悪循環の構造

```
赤字が拡大
  ↓
賃上げできない
  ↓
優秀な人材が他業種へ流出
  ↓
人手不足で医療の質が低下
  ↓
患者が減る
  ↓
収入がさらに減る
  ↓
赤字がさらに拡大（最初に戻る）
```

この**負のスパイラル**に陥っています。

---

### 要因4：物価高騰と診療報酬のタイムラグ

#### 物価高騰の実態

2022年頃から、急激な物価高騰が起きています。

**主な項目の値上がり：**
- 電気代：約2倍
- ガス代：約1.5倍
- 食材費：10〜30%増
- 医療材料費：5〜15%増
- 医薬品費：品目により値上がり

#### 診療報酬は後追い

**問題の構造：**

```
2022年4月：前回の診療報酬改定
  ↓
2022年後半〜：物価急騰スタート
  ↓
2024年4月：診療報酬改定（2年後）
  ↓
2024年後半〜：さらに物価上昇
  ↓
2026年4月：次の改定（さらに2年後）
```

**つまり：**
- 物価は「今」上がる
- 診療報酬は「2年後」に少し上がる
- その間、病院は赤字を垂れ流す

#### 具体的な影響

**2022年〜2024年の2年間：**
- 物価上昇率：累積で10%以上
- 診療報酬改定（2024年）：本体1.88%のみ

→ **物価上昇の1/5程度しかカバーできていない**

**2024年〜2026年の2年間：**
- 物価上昇：継続中
- 診療報酬改定（2026年）：3.09%
  - しかし、過去の分と合わせると依然として不十分

→ **常に「追いついていない」状態**

---

### 要因5：賃上げ原資を配分する仕組みの問題

#### ベースアップ評価料とは

2024年の診療報酬改定で導入された仕組みです。

**概要：**
- 初診・再診時や入院時に、追加で点数を算定できる
- その収入を、職員の賃上げ原資に充てる

**例：**
- 外来・在宅ベースアップ評価料
- 入院時のベースアップ評価料

#### 問題点1：患者数に依存する

**仕組み：**
```
患者が多い病院 → ベースアップ評価料の収入が多い → 賃上げできる
患者が少ない病院 → ベースアップ評価料の収入が少ない → 賃上げできない
```

**問題：**
- 経営が苦しい病院ほど、患者数が減っている
- つまり、**困っている病院ほど、賃上げ原資が得られない**

#### 問題点2：全職員に行き渡らない

ベースアップ評価料で得られる収入は限定的です。

**試算例（中規模病院の場合）：**
- 年間のベースアップ評価料収入：約3,000万円
- 職員数：200人
- 一人当たり：15万円/年（月1.25万円程度）

**これで5%の賃上げができるか？**
- 平均年収400万円の職員の5%賃上げ：20万円/年
- しかし、実際に得られるのは15万円/年
- **不足分：5万円/年 × 200人 = 1,000万円**

→ 自己資金から1,000万円を追加で捻出する必要がある
→ しかし、赤字の病院にその余裕はない

#### 問題点3：事務負担の増加

ベースアップ評価料を算定するには：
- 賃上げ実績の報告が必要
- 詳細な記録と提出義務
- 事務作業の増加

→ **人手不足の病院では、この事務負担自体が重荷**

## 各要因の関係性：構造図

これらの要因は、互いに関連し合っています。

```
【構造図】

診療報酬（公定価格）
    ↓
収入が固定される
    ↓
物価高騰 → 支出は増加
    ↓
収支バランス悪化
    ↓
赤字が拡大（74.6%の病院が赤字）
    ↓
人件費比率が限界に（56〜58%）
    ↓
賃上げ不可能
    ↓
人材流出（他業種は5.10%の賃上げ）
    ↓
人手不足
    ↓
医療の質低下・患者減少
    ↓
収入減少
    ↓
さらに赤字拡大（負のスパイラル）


【一方で】
診療報酬改定（2年に1度）
    ↓
わずかに収入増（3.09%）
    ↓
しかし物価高騰（それ以上）に追いつかず
    ↓
構造的問題は解決せず
```

## 他業種との比較：なぜ他業種は賃上げできるのか

### 他業種（製造業、サービス業など）

**価格決定の自由：**
- コストが上がれば、商品・サービスの価格を上げられる
- 市場の需要と供給で価格が決まる

**賃上げの原資確保：**
```
物価上昇
  ↓
商品価格を値上げ
  ↓
収入増加
  ↓
賃上げの原資が生まれる
  ↓
5.10%の賃上げ実施
```

### 医療業界

**価格決定の制約：**
- コストが上がっても、診療報酬は変わらない
- 国が2年に1度しか見直さない

**賃上げの原資確保：**
```
物価上昇
  ↓
診療報酬は据え置き（2年間）
  ↓
収入は変わらず、支出だけ増加
  ↓
赤字が拡大
  ↓
賃上げの原資がない
  ↓
2.41%の賃上げが限界
```

**決定的な違い：**
| 項目 | 他業種 | 医療業界 |
|------|--------|----------|
| 価格決定 | 自由 | 公定価格 |
| 価格改定 | いつでも | 2年に1度 |
| 物価転嫁 | 可能 | 不可能 |
| 賃上げ原資 | 価格転嫁で確保 | 診療報酬改定待ち |
| 賃上げ率（2024年） | 5.10% | 2.41% |

## 数字で見る賃上げの困難さ

### ケーススタディ：中規模病院（150床）

**前提条件：**
- 医業収益：年間10億円
- 職員数：200人
- 現在の人件費：5億6,000万円（人件費比率56%）
- 現状：ギリギリ黒字（利益率1%）

#### パターン1：他業種並み（5.10%）の賃上げをした場合

**人件費の増加：**
```
5億6,000万円 × 5.10% = 2,856万円
```

**新しい人件費比率：**
```
(5億6,000万円 + 2,856万円) ÷ 10億円 = 58.86%
```

**経営への影響：**
- 人件費比率が58.86%に上昇（危険水域に接近）
- 利益1,000万円 → 赤字1,856万円
- **即座に赤字転落**

#### パターン2：診療報酬改定（3.09%）の収入増を活用した場合

**収入の増加：**
```
10億円 × 3.09% = 3,090万円
```

**これで何%の賃上げが可能か：**
```
3,090万円 ÷ 5億6,000万円 = 5.52%
```

一見、5.52%の賃上げができそうですが、**これは間違いです**。

**なぜか：**
診療報酬改定の3.09%のうち：
- 賃上げ対応：1.70%
- 物価高対応：1.29%
- その他：0.10%

**実際の賃上げ原資：**
```
10億円 × 1.70% = 1,700万円
```

**これで可能な賃上げ率：**
```
1,700万円 ÷ 5億6,000万円 = 3.04%
```

→ **3.04%の賃上げが限界**
→ 他業種（5.10%）には遠く及ばない

#### パターン3：物価高騰の影響を考慮した場合

診療報酬改定で収入が3.09%増えても、物価高騰で支出も増えます。

**物価高騰による支出増：**
- 電気・ガス：年間500万円増
- 食材費：年間200万円増
- 医療材料費：年間300万円増
- 合計：年間1,000万円増

**実際の賃上げ可能額：**
```
診療報酬改定による収入増：3,090万円
物価高騰による支出増：1,000万円
実質的な賃上げ原資：2,090万円
```

**可能な賃上げ率：**
```
2,090万円 ÷ 5億6,000万円 = 3.73%
```

→ **3.73%が現実的な上限**
→ 依然として他業種（5.10%）に届かない

## 解決策はあるのか？

### 短期的な対策（限定的）

#### 1. 診療報酬のさらなる引き上げ

**必要な改定率：**
他業種並みの賃上げ（5.10%）を実現するには、診療報酬本体を**少なくとも5〜6%引き上げ**る必要があります。

**問題点：**
- 診療報酬1%の引き上げ = 医療費5,000億円増
- 5%の引き上げ = 医療費2.5兆円増
- 財源は国民の税金・保険料負担増
- 政治的に実現困難

#### 2. 物価スライド制の導入

**提案内容：**
物価上昇率に応じて、自動的に診療報酬を調整する仕組み

**メリット：**
- タイムラグがなくなる
- 物価高騰に即座に対応可能

**問題点：**
- 医療費が際限なく増える可能性
- 現在の制度の大幅な変更が必要

### 中長期的な対策（構造改革）

#### 1. 医療DXによる効率化

**内容：**
- 電子カルテの完全導入
- AI診断支援
- オンライン診療の拡大
- 業務の自動化

**期待効果：**
- 人手不足を補う
- 業務効率が上がれば、少ない人数で同じ医療を提供できる
- その分、一人当たりの給与を上げられる

**問題点：**
- 初期投資が莫大（経営難の病院には無理）
- 高齢の医療従事者のデジタル対応が困難
- すぐには効果が出ない

#### 2. 機能分化と集約

**内容：**
- 大病院：重症患者に特化
- 中小病院・診療所：軽症患者や慢性疾患
- 役割を明確に分け、効率化

**期待効果：**
- 重複投資を避ける
- 各病院が得意分野に集中できる
- 経営効率が上がる

**問題点：**
- 病院の統廃合が必要（地域医療の空白化リスク）
- 実現には10年以上かかる

#### 3. 混合診療の部分解禁

**内容：**
保険診療と自由診療を組み合わせられるようにする

**期待効果：**
- 病院が自由価格で設定できる部分が増える
- 収入増の可能性

**問題点：**
- 「お金持ちしか良い医療を受けられない」格差が生まれる
- 国民皆保険制度の理念に反する
- 政治的に極めて困難

## 結論：なぜ医療業界は賃上げが困難なのか

### 5つの要因の総まとめ

1. **診療報酬（公定価格）の壁**
   - 価格を自由に決められない
   - 2年に1度しか改定されない

2. **人件費比率の限界**
   - すでに56〜58%（限界は60%）
   - これ以上上げると経営破綻

3. **深刻な赤字状態**
   - 74.6%の病院が赤字
   - 赤字なのに賃上げは不可能

4. **物価高騰とのタイムラグ**
   - 物価は今上がる、診療報酬は2年後
   - 常に「追いつかない」

5. **賃上げ原資配分の仕組みの問題**
   - ベースアップ評価料では不十分
   - 困っている病院ほど恩恵が少ない

### これらの関係性

これらは独立した問題ではなく、**互いに絡み合って「構造的な問題」を形成**しています。

```
公定価格 → 収入が固定
    +
物価高騰 → 支出が増加
    =
赤字が拡大
    ↓
人件費比率が限界に達する
    ↓
賃上げ不可能
    ↓
人材流出
    ↓
医療崩壊のリスク
```

### 本質的な問題

**「診療報酬制度」という仕組み自体が、急激な物価変動に対応できない**

物価が安定していた時代には機能していましたが、今のような急激な変動には対応できません。

## 私の考察

この問題を調べて痛感したのは、**個々の病院の努力では解決できない「制度の問題」**だということです。

病院が経営努力をしても、診療報酬という公定価格に縛られている限り、賃上げの原資は生まれません。

一方で、診療報酬を大幅に引き上げれば、国民の負担（税金・保険料）が増えます。

**誰も悪者がいない、構造的なジレンマ**です。

医療業界で働く人（または目指す人）は、この構造を理解した上で：
- 病院以外のキャリアパス（在宅、予防、健康産業）を視野に入れる
- 専門性を高めて、少ない人数でも高い給与が得られる分野を目指す
- 副業・複業で収入を多様化する

といった戦略が、ますます重要になると感じます。
